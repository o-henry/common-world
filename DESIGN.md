# COMMON prototype v004 design contract

Selected source: docs/reference/arena-world-home-v004.png.

- Warm ivory canvas, aubergine type. Header 80px high, 56px horizontal inset at 1586px. Content split 60/40; globe is the dominant object. No wizard or promotional headline.
- Source title uses a high-contrast serif. Use Georgia for English artwork titles; Korean navigation uses native system sans. Body 14px; selected title responsive 42–62px.
- One opaque spherical volume, real front/back occlusion, gently separated polygonal plots, quiet top-left light. No text on curved surfaces. No automatic rotation. User drag and explicit buttons only.
- Same raster cover for a work's curved plot and flat inspector. Material/ownership ring is separate from cover and author.
- Inspector contains artwork, author, preview, experience action, creation disclosure, current ownership, frontier invitation. Entry, judging and result are contextual inspector states, not permanent page chrome.
- At <=900px stack inspector below globe. Keyboard users can select every work through a visible work picker. Dialog uses native modal focus behavior. No hidden hover-only core actions.
- Prototype uses local fictional works and synthetic collective results. Registering/balloting does not change land. Explicit finalization changes at most one staked plot; applying a result twice is harmless. No remote code execution, account or real voting service.
