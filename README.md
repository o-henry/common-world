# COMMON

AI 진영이 결과물로 겨루고, 판정에 따라 접경의 영토가 바뀌는 웹 프로토타입입니다. 구체에서 전황을 보고 같은 좌표의 지역 지도로 확대합니다. 작품·원작자·제작 AI 신고는 현재 점유 진영과 별개입니다.

## v008: 두 접경을 비교해서 출전하기

Node.js 24에서 실행·검사합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

http://127.0.0.1:4173/ 에서:

1. **전황**에서 재도전 접경과 피드백 접경의 공통 조건, 걸린 칸, 승리·패배 뒤의 다음 경계를 비교합니다. **지도에서 위치 보기**는 미리보기이며 영토나 선택을 바꾸지 않습니다.
2. **이 접경 선택 → 선택한 접경에 출전**을 누릅니다. 선택만 한 상태에서는 바꿀 수 있고, 한쪽이라도 출품하면 이번 판정 전까지 다른 접경으로 옮길 수 없습니다.
3. **접경전**에서 양쪽 후보를 각각 출품합니다. 제출 파일·버전·제작 신고가 고정됩니다. 기본 제작자 역할은 ‘참고 구현 제작자’입니다.
4. **작품 A / B 실행하기**로 타이밍 점프 게임과 궤도 전환 게임을 직접 플레이합니다. 두 작품을 체험한 뒤 부모 화면에서 체험 완료를 선언합니다.
5. 해당 과제의 필수 기능 확인과 선호 투표를 따로 제출합니다. 기능 확인은 평가자의 수기 관찰이며 앱 메시지나 테스트 통과를 자동 판정으로 사용하지 않습니다. 확정 전에는 선택별 집계를 숨깁니다.
6. **평가·조건 확인 후 결과 확정**을 누릅니다. 실제 저장된 응답으로 집계하며 임의의 승패 시나리오는 없습니다. 양쪽 필수 기능이 확인된 경우 전체 유효 응답의 과반이 선호 승리에 필요합니다. 보류·동률·평가 부족에서는 경계를 유지합니다.
7. **변경된 다음 접경 비교하기**로 이어갑니다. 승리하면 획득한 칸 주변, 패배하면 남아 있는 인접 아군 칸 주변의 실제 경계가 다음 후보가 됩니다. 판정 근거는 다음 접경을 선택한 뒤에도 읽기 전용으로 열립니다. 이전 제출 파일과 기록은 유지합니다.

연습 정족수는 **로컬 역할의 응답 1건**입니다. 실제 독립 평가자 1명이나 공개 대회 판정 기준을 뜻하지 않습니다.

## 실제로 무엇이 있나요?

두 기본 HTML 게임은 실제로 조작·진행·충돌·점수·재시작이 동작하는 참고 구현입니다. 둘 다 같은 Codex 세션에서 작성했습니다. **Claude/OpenAI 진영 배치는 인터페이스 연습용이며, 서로 다른 AI의 실제 출품이나 성능 자료가 아닙니다.** 독립적으로 확인한 AI 경기 데이터는 아직 없습니다.

**결과물 출품**에서 자기 진영, 실제 사용 AI 신고, 에이전트·모델 버전·사람 개입·제작 조건과 단일 HTML 파일을 등록할 수 있습니다. 사용 AI 신고와 출전 진영은 분리합니다. 최초 제작자와 일치하는 로컬 역할만 수정하며 새 HTML/메타데이터도 새 버전으로 보존합니다. 다른 진영의 빈 자리에 등록하거나 중립 땅을 무상 지급하지 않습니다.

v008은 **Claude 관점의 국지전 연습**입니다. 현재 기준 칸과 바로 연결된 아군 칸의 실제 접경 중 최대 두 곳을 제시합니다. 상대는 실제 점유 진영이며, 작품이 없으면 출품 대기로 표시합니다. 후보가 한 곳이거나 없으면 그대로 표시하고 중립 땅을 지급하지 않습니다. 승패 예고는 조건부 다음 경로이며 승리 확률이 아닙니다. 영토가 많다고 평가나 투표에 보너스를 주지 않습니다. 임의 두 진영의 경기를 만드는 이전 v007은 별도 경로로 유지합니다.

## HTML 실행과 보안 경계

- 업로드는 자체 포함 단일 HTML, UTF-8 기준 최대 256KiB입니다. 외부 CDN·API·추가 파일이 필요한 프로젝트는 이 미리보기 형식에서 지원하지 않습니다.
- 명시적 실행 버튼 뒤에만 `sandbox="allow-scripts"` iframe의 `srcDoc`로 렌더합니다. `allow-same-origin`, 팝업·상위 탐색·폼·다운로드 허용 권한을 추가하지 않습니다. 원본 HTML을 부모 DOM에 넣지 않습니다.
- 문서 앞의 CSP가 fetch·worker·frame·object·외부 자원 등을 제한합니다. **iframe 자체 탐색을 모든 브라우저에서 막는 완전한 네트워크/프로세스 격리는 아닙니다.** 임의 공개 업로드의 안전한 호스팅이나 실서비스 서버 격리를 구현했다는 뜻이 아닙니다.
- SHA-256은 파일의 동일성을 확인하는 식별값이며 AI 제공자·작성자·단일 모델 사용을 증명하지 않습니다.
- 계정 인증·실제 제작자 권한·다중 사용자 투표·독립 평가자 확인·조작 방어 서버는 아직 연결되지 않았습니다. 이 브라우저에서 제작자/평가자 역할을 시연합니다.

## 저장과 복구

v008은 `common:campaign:v1`을 사용합니다. v007의 `common:competition:v1`과 이전 `common:frontier-league:v1`, `common:frontier-neighborhood:v1`은 읽거나 수정·삭제하지 않습니다. 이전 출품·기록은 해당 버전의 화면에서 볼 수 있습니다. 업로드 HTML·표지는 브라우저에 보관되며 공개 Git에 추가하지 않습니다. 브라우저 저장은 영구 백업이 아닙니다. 손상 기록은 보존하며 명시적 초기화 전에는 덮어쓰지 않고, 용량 실패 시 이전 성공 저장본을 유지합니다.

v007 화면은 `?legacy=v007`, v006은 `?legacy=v006`입니다. 이전 소스는 `prototype-v007`, `prototype-v006` 태그로 복구합니다. [복구 방법](docs/RECOVERY.md).
